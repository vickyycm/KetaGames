Políticas de Privacidad

En KetaGames, la privacidad de nuestros usuarios y la integridad de sus datos es fundamental para el análisis de nuestra plataforma.

Tratamiento y Persistencia de Datos

Toda la información recolectada en este sitio, incluyendo nombres de usuario, sesiones de juego, intentos realizados y puntuaciones obtenidas, se almacena de forma segura mediante un sistema de persistencia de datos administrado de forma interna.

Uso de APIs y Modelos de IA

La plataforma consume APIs externas e Inteligencia Artificial para el procesamiento semántico y la generación dinámica de las temáticas. Ningún dato sensible del usuario es enviado a estas APIs de terceros; las consultas se limitan estrictamente a las palabras clave necesarias para estructurar los desafíos del Wordle, Rosco y Contexto.

Finalidad Académica

Este sistema fue diseñado con fines exclusivamente educativos y de validación de arquitectura de software para la Escuela Da Vinci. No se comercializan ni comparten datos con entidades externas.
